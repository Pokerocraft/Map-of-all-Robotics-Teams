# Open Source Map Project


Basically, this project is meant to be a map of all teams in FIRST Robotics Competition (Or FRC) based on cities, the data from most teams will be pulled from The Blue Alliance or the FIRST Robotics website. 

# Adding Cities to the Map
If you want to add cities to the map, just grab the ID from, and I'm using Ypsilanti, Michigan, USA, as an example, https://www.openstreetmap.org/relation/135135#map=13/42.24992/-83.64278, grab the the numbers before #map, in this case, 135135, and plug it into https://polygons.openstreetmap.fr/get_geojson.py?id= with the ID at the end. Then download that as, say, ypsilanti.geojson, then go into src/main/geojsons, and locate the country and state, if applicable, then plug the city GeoJSON file there, then go into the code, add a list of GeoPositions with the name of your city, state (if applicable), and country followed by PolygonPoints, you're then going to want to call parseGeoJsonFile, with the parameter of new File, and then where your city is located. You'll then call the PolygonalPainter, similarly to the list of GeoPositions, call the variable similar to that, but instead use the suffix of PolygonPainter. You'll then make a new PolygonalPainter object, and put in your polygonPoints variable, plus 2 colors of your choosing (In RGBA format), then just add the PolygonPainter object you created into the setPainters method from compoundPainter. Make sure in your GeoJSON to remove enough curly braces so that it's only a list of a list of a double for coordinates, elsewise the code will fail to compile
